# 玩猫一时爽，猫癣上身，难治愈

> 更新时间：2026-09-16 (UTC+8)

接诊医生：徐春云（皮肤科）  

有个小朋友来复诊了，但我已经记不起他是因为什么来就诊过了

他妈妈提醒我，就是那个脸上长癣，去了好几个医院治疗了半年不好，说不行要吃药的那个小孩。

我的记忆一下就回到当时

第一次来的时候面部皮疹如下图

妈妈：各种药膏用了一大堆（抗真菌的，激素等），就是不好，药膏停了就起来，断断续续，跑了好几个医院治了半年了。

家里有猫，猫有生病，我也被传染了猫癣，但我身上用药好了，孩子脸上这块就是好不了，愁坏了。

这不就到我们医院来了，看看还有什么好办法。

实话，当时我也没有把握。因为时间太久，离眼睛近，一旦感染眼部很麻烦。所以当时提了，可以口服抗真菌药物治疗。家长担心口服药物的副作用，没有同意。

就让她把以前的药膏全停了，尤其含激素的药膏。

即使反复起来也不要再用含激素药物。

给孩子开了3种没有激素的药膏搭配使用，抗炎、抗真菌、修复保护皮肤。

交待其过段时间来复诊。

当时也没有把握会不会控制住，能不能回来复诊。

好在家长遵医嘱一直坚持使用，虽然停了原来的药膏后，皮疹第二天就有加重。但家长坚持了下来，逐渐逐渐皮疹减轻，家长一天天拍照记录，看到变化很高兴。

来复诊的时候诊室内正常光线，仅凭肉眼看，不说是那个地方，很难看出来了

所以来复诊的时候很高兴。

家长人很好，给我发了照片，当时孩子不配合拍照，回家又给我发了现在的照片。

门诊被猫感染，一家人都得癣的人真的很多。

尤其小孩子，容易被感染得面癣/体癣/头癣

玩猫一时爽，猫癣上身，难治愈

不是一句玩笑话

  这里提醒大家  

家里养宠物/饲养动物（包括猫、狗、兔子、狐狸等）的朋友。一定要注意动物的皮肤健康，有脱毛皮屑及时治疗，避免家里成员被感染真菌（癣）。
